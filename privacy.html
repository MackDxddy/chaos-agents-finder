Privacy Policy

Bobo's Insider Trading · Last updated: August 30, 2026

Bobo's Insider Trading does not collect, transmit, or sell any personal data. It is a companion tool for the browser game Chaos Agents, and everything it does runs locally in your browser.

What the extension stores

Your favorites, filter preferences, and a local copy of the game's agent and skill catalogue are saved in your browser's local storage so the tool loads quickly and remembers your settings between visits. This information stays on your device and is never sent anywhere.

Your game login

To show which agents are available on your account, the extension reads your existing Chaos Agents login token from the game's own website, in your browser. It uses this token only to request your account's agent availability from the game's own API — the same server that issued the token. The token is never sent to the developer or to any third party, and it is not stored anywhere outside your own browser.

Data sharing

None. No data is transmitted to the developer, and no data is shared with, sold to, or transferred to any third party. The extension makes network requests only to the Chaos Agents website (chaos-agents.popularium.com) and only to fetch game data for you.

Remote code

All of the extension's code is contained within the installed package. It does not load or run any code hosted elsewhere.

Changes to this policy

If this policy changes, the updated version will be posted here with a new "last updated" date.

Contact

Questions about this policy can be directed to the extension's developer through the listing page on the Chrome Web Store or Firefox Add-ons.

Bobo's Insider Trading is an unofficial, fan-made tool and is not affiliated with the makers of Chaos Agents. Game names and content belong to their respective owners.
